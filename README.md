## Frequently Asked Questions
1. **Wait, we get to use AI tools?!** Yes... you may use AI tools to complete this assignment. ***ONLY this assignment.***
2. **So, if I'm using AI generated code, is there anything for me to do?** Yes! Most available AI code writing tools are large language models (LLMs) that predicts text based on all of the stuff it was given in training. Sometimes it produces good code, and sometimes the code doesn't work for all cases. If the code generated doesn't work (for all test cases) it's up to you to figure out how to fix that.
3. **If AI tools can write code, why do I need to learn to write code?** For the same reason you needed to learn basic math before you learned to use a calculator. Artificial intelligence is a really cool tool, but you need to understand its limitations for it to be useful in your work. You must understand the structure of code and how to solve a problem before you can identify and fix any issues in the code. In other words, you need to know how to read and write code to figure out if someone (or something) else's code is good or just junk.
